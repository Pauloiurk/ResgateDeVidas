# Resgate de Vidas

Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso de Ciência da Computação.

O **Resgate de Vidas** é um sistema desenvolvido com o objetivo de auxiliar no gerenciamento e organização de informações relacionadas ao projeto.

## Migração para Web

O sistema foi originalmente desenvolvido como uma aplicação desktop em **Python**.

Atualmente, o projeto está passando por um processo de migração para uma arquitetura Web, buscando melhorar a acessibilidade, manutenção e evolução do sistema.

### Tecnologias utilizadas

- Python
- Django
- PostgreSQL
- Docker
- Git e GitHub

## Estrutura do projeto

Este repositório mantém o código da versão original do sistema e servirá como base para o processo de migração para Web.

A versão desktop final está preservada através da tag:

`versao-desktop-final`

## Objetivo

Transformar a aplicação desktop em uma solução Web moderna, mantendo as funcionalidades existentes e permitindo futuras melhorias e expansões.
